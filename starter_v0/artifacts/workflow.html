Research Paper Scout Agent

Sơ đồ luồng xử lý (Workflow) & Hệ thống Tools (Gemini 3.1 Flash Lite — 100% Accuracy)

Danh sách Tools Agent Đang Sử Dụng

find_paper_code Tool Mới (Custom)

Tìm kiếm mã nguồn mở (official / community GitHub repositories) đi kèm của bài báo khoa học dựa trên tên bài báo, arXiv ID hoặc từ khóa.

Input: query="Attention Is All You Need"

papers Research Core

Tra cứu danh sách bài báo khoa học trên arXiv theo từ khóa chủ đề và tiêu chí sắp xếp ngày đăng.

Input: query="Mixture of Experts"

paper_text Research Core

Trích xuất văn bản chi tiết từ PDF bài báo arXiv dựa vào URL hoặc arXiv ID.

Input: arxiv_url="2312.00752"

clarify Boundary & Control

Hỏi lại người dùng khi thiếu thông tin (Handle, URL) hoặc xin xác nhận yes_no trước hành động nhạy cảm (Telegram).

Input: response_type="yes_no"

lookup Web & News

Tìm kiếm thông tin tin tức thời sự trên Internet. Tham số query giữ từ khóa tối giản ngắn gọn.

Input: query="AI", topic="news"

social_search Social Search

Tìm kiếm các bài đăng trên mạng xã hội Twitter theo từ khóa (Latest hoặc Top).

Input: query="GPT-5", search_type="Top"

timeline Social Timeline

Lấy bài đăng mới nhất của tài khoản cụ thể theo screenname/handle (VD: sama, elonmusk).

Input: screenname="sama"

fetch Web Content

Đọc nội dung văn bản trực tiếp từ một đường dẫn URL bài viết cụ thể.

Input: url="https://..."

format Formatting

Tổng hợp các items dữ liệu đã thu thập thành bản tin tóm tắt Markdown đẹp mắt.

Input: template="sections"

send Action

Đăng bài lên Telegram (chỉ kích hoạt sau khi người dùng đã xác nhận Yes/No qua tool clarify).

Input: text="...", confirmed=true

Các Bước Trong Vòng Lặp Xử Lý Trực Tiếp (Agent Execution Loop)

1

Tiếp Nhận Request & Phân Tích Ý Định (Intent Analysis)

Hệ thống nhận input từ người dùng (Streamlit UI hoặc CLI) và chuyển đến Gemini Provider với System Prompt ranh giới chuẩn mực.

2

Đánh Giá Ranh Giới (Boundary & Policy Check)

Nếu là câu hỏi ngoài phạm vi (Toán học/Meta) ➔ Trả lời trực tiếp không dùng Tool (No-Tool). Nếu thiếu thông tin/cần đăng bài ➔ Gọi clarify với response_type chuẩn.

3

Thực Thi Tool Trực Tiếp Hoặc Song Song (Tool Execution)

Thực thi các hàm Python thực tế (như tra cứu GitHub API trong find_paper_code hoặc arXiv API trong papers). Hỗ trợ gọi song song nhiều tool khi cần thiết.

4

Tổng Hợp & Phản Hồi Kết Quả (Digest & Response)

Kết quả từ Tool được định dạng thành Markdown đẹp mắt, hiển thị Trace gọi Tool minh bạch trên Streamlit UI và lưu lại JSON Log làm bằng chứng.
